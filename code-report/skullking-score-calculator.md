# 스컬킹 점수 계산기 — 개발 근거 (2026-08-31)

## 요구사항
- HTML/CSS/JS만 사용, S3 정적 업로드로 지인 공유 (저장소 관리 안 함)
- 모드 2개: **모두**(여럿 합산) / **나**(개인 기록)
- 게임 선택(현재 스컬킹), 프리셋 7명(파비·효명·엘라·동원·주령·서온·유찬) + 게스트 이름 추가

## 핵심 설계 결정
1. **단일 index.html (CSS/JS 인라인)** — S3에 파일 1개만 올리면 끝. 파일 분리 시 업로드 3개 + 경로 관리가 오히려 부담.
2. **스컬킹 신판(Grandpa Beck's 2021) 규칙 채택** — 구판과 보너스가 다름. 현재 유통판 기준:
   - 비드 성공: 트릭 × 20 / 실패: 차이 × -10
   - 0비드: 라운드 × ±10
   - 보너스(비드 정확 + 트릭 1개 이상일 때만): 일반14 +10(최대3), 검정14 +20(최대1), 해적→인어 +20(최대2), 스컬킹→해적 +30(최대5), 인어→스컬킹 +40(최대1)
   - 근거: BGA 게임 도움말, Grandpa Beck's 공식 룰, UltraBoardGames
3. **스테퍼(+/−) 입력** — 모바일에서 숫자 키보드 팝업 없이 빠른 입력. 비드/트릭 상한 = 라운드 번호로 잘못된 값 원천 차단.
4. **트릭 합계 검증(모두 모드만)** — 전체 획득 트릭 합 = 라운드 번호가 아니면 제출 거부. 나 모드는 다른 사람 트릭을 모르므로 검증 생략.
5. **localStorage 저장/복구** — 술자리/모임 중 새로고침·화면 꺼짐으로 점수 날아가는 것 방지. 복구 시 스키마 엄격 검증(플레이어 수 1~8, round 1~10 정수, 점수 전부 유한 숫자) — 손상 데이터로 인한 크래시/self-XSS 차단.
6. **게스트 이름 XSS 방지** — 모든 이름 출력은 textContent 또는 escapeHtml 경유.

## 검증
- 로컬 HTTP 서버 + 브라우저 자동화로 전 흐름 확인: 설정(중복 이름 거부, 8명 상한) → 10라운드(성공/실패/0비드/보너스 적용·미적용/트릭 합계 오류) → 최종 순위·동점 우승 → 같은 멤버 재시작 → 나 모드 → 손상 localStorage 복구 무시.
- 코드 리뷰 1회 실행(Critical 0, Important 3, Minor 8) → Important 전건 + Minor 6건 수정 완료. 미수정 Minor: 로드 시 confirm() 사용(의도된 단순함), title 툴팁 유지.

## 5차 변경 (2026-08-31, 동일 세션): 게임별 배경/마스코트, 사이드 메뉴, 폰트 고정
1. **게임 선택 흐름 재구성**: 하위 모드(variants)를 별도 화면으로 분리하지 않고 게임 선택 화면 자체에 "게임명 · 모드명" 카드로 펼침(예: "티츄 · 팀전", "티츄 · 쟁상유"). 카드 클릭 시 게임+모드가 동시에 확정되고 바로 모두/나 선택으로 진입. `screen-variant` 화면과 관련 함수는 완전히 제거.
2. **좌측 상단 햄버거 메뉴**: 슬라이드인 사이드 드로어에 "게임 선택"/"모두·나 선택" 두 메뉴. "모두·나 선택"은 게임 미선택 시 비활성화. 점수 입력 중(게임 진행 화면)에 메뉴로 이동하면 그만하기와 동일한 확인 모달이 뜨고, 확인 시 해당 목적지로 이동(모두·나 선택을 고르면 게임은 유지한 채 모드만 리셋, 게임 선택을 고르면 전체 초기화). 접근성: 메뉴 오픈 시 `inert`로 배경 포커스 차단, Escape로 닫기 지원.
3. **게임별 배경 시스템**: 게임 선택 시점부터 결과 화면까지 body 배경이 게임별로 바뀜(스컬킹: 짙은 틸 그라데이션, 티츄: 짙은 적색 단색 — 색상은 참고 이미지에서 흰색을 제외하고 추출). 어두운 배경에 맞춰 헤더 타이틀, 라운드 배지, 카드 밖에 노출되는 ghost 버튼 4종(그만하기/뒤로가기 2종/게임 선택으로)의 색을 자동 보정하는 규칙을 추가.
4. **배경 마스코트 일러스트 교체**: 기존의 거의 안 보이는 실루엣 워터마크(5~7% 불투명도) → 눈·볼터치가 있는 귀여운 치비 스타일 오리지널 일러스트(해적 선장 / 용)로 다시 그리고 불투명도를 22~42%로 올려 실제로 알아볼 수 있는 마스코트가 되도록 함. 두 이미지 모두 실제 캐릭터나 원본 박스아트를 그대로 트레이싱하지 않은 자체 디자인 — 특정 캐릭터(디즈니 후크 선장)나 특정 게임사의 박스아트를 그대로 복제하는 것은 저작권 문제가 있어 피하고, 대신 색감만 참고해 원본 일러스트를 새로 그림.
5. **폰트 고정**: 시스템 폰트(Apple SD Gothic Neo 등)가 우선 적용되던 것을 Pretendard로 고정. 빌드 도구가 없으므로 jsDelivr CDN(`pretendard@v1.3.9`)에서 웹폰트를 로드.

- 세션 외부에서 스컬킹에 "커스텀 모드"(현재 라운드 수동 조정 + 점수 계산 후 라운드 자동 상승 on/off)와 "이전 라운드 점수 수정" 기능이 추가되어 있었음(파일 재확인으로 발견).
- 버그 리포트: "커스텀모드 + 라운드 고정으로 진행 중 고정을 풀어도 고정되어있는 현상".
- 원인: `common.js`의 `toggleSkullkingCustomMode()`가 커스텀 모드 체크박스를 켜고 끌 때마다, 화면에서 숨겨져 있을 뿐 DOM에는 남아있는 "자동 상승" 하위 체크박스의 `.checked` 값을 그대로 읽어와 `state.skullkingAutoAdvance`에 덮어썼음. 자동 상승을 한 번이라도 꺼서 라운드를 잠근 적이 있으면, 커스텀 모드를 껐다 다시 켜는 것만으로 사용자가 건드리지 않은 잠금이 조용히 되살아남.
- 수정: 커스텀 모드 토글 핸들러에서 `skullkingAutoAdvance`를 숨겨진 체크박스 값을 참조하지 않고 항상 `true`(기본값)로 리셋하도록 변경. 오직 자동 상승 체크박스 자신의 change 리스너만 이 값을 false로 만들 수 있게 분리.
- 검증: 브라우저에서 정확히 같은 재현 절차(커스텀모드 on → 잠금 → 커스텀모드 off → 커스텀모드 on)로 버그 재현 후 수정 확인, 기존 잠금/해제/라운드 스테퍼 회귀 없음 확인. 코드 리뷰 1회 추가(ready).
